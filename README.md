# The Embedded Rust Project

This is is my tutorial repo as I work through the book.

## Book Reference

This project follows **[Embedded Rust](https://rust-embedded.org)'s** [Embedded Rust](https://docs.rust-embedded.org/book/), an introductory guide to using the Rust Programming Language on "Bare Metal" embedded systems and microcontrollers.

## Environment setup

Install rust on your system following the [Rust Language](https://rust-lang.org) install guide.
Then, in your own Projects directory, run ``cargo new --edition 2018 embedded_rust_book``.

You should now be configured identically to the book.
